# 🎵 React Music Player & Card UI

 React project built using React and  CSS. This project focuses on practicing fundamental React concepts while creating a simple and clean UI.

## 🚀 Features


- Dynamic song title and lyrics using Props.
- Reusable React Components.
- Props passing between components.


## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS

## 📚 React Concepts Practiced

- `useState` Hook
- Creating Components
- Passing Props
- Component Reusability
- Dynamic Data Rendering

## 🎯 Learning Objective

The main objective of this project is to understand React fundamentals, component-based architecture, state management, and props communication while building a responsive user interface.

## 💻 Installation

```bash
npm install
npm run dev
```
